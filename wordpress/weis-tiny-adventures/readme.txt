An editable block theme preserving Wei's watercolor travel journal.

INSTALLATION
1. Install and activate the included Wei's Travel Tools plugin ZIP.
2. Upload and activate this theme in Appearance > Themes.
3. Open Appearance > Set up Wei's journal and import the travel journal.

EDITING
Pages: homepage, biography, travel tips, signup introduction and other page copy.
Posts: articles, country assignment, featured photos, and Coming soon status.
Destinations: postcard copy, featured image, continent, country and coordinates.
Appearance > Editor: navigation, shared header/footer and templates.
Tools > Newsletter: active subscribers and export. Email sending is not connected.

The importer adds bundled starter content and photos without resetting existing
matching pages or earlier imports. No React/Node build tools are required to run
the installed theme. More detailed installation and Docker instructions are in
the accompanying wordpress/README.md.

ASSETS
Self-hosted fonts retain their SIL Open Font License files in assets/fonts.
Photo and artwork attributions are in ASSET-CREDITS.md and assets/images credit
files. Those assets retain their original licences.
