# Travel tips design

Extend the existing coastal journal as a useful field guide. Preserve the navy, marine blue, pale paper, local Cormorant/Allura/Lato fonts, Phosphor icons, handwritten notes, postcard photography, and watercolor texture. The page has its own responsive layout and uses the existing shared header.

The main action goes directly to the official-advice lookup. A split postcard hero and compact chapter links lead into a prominent navy/paper safety section, a ruled expandable field guide, and a packing checklist. The final postcard links back to the adventure atlas. Existing local image assets are reused; no new raster assets or runtime external image requests are needed.

Design variance 5, motion 2, visual density 3. Pill buttons, subtly squared paper panels, readable mobile type, native controls, explicit labels, keyboard focus, and reduced-motion support follow the existing brand. No copied safety ratings or fabricated trip accounts.

The field guide switches between three everyday travel topics. Checklist state is local to the reader's device with a storage-failure fallback and downloadable text. Official safety advice always opens at its source so readers see the current information.
